# README.md# Personal Website

这是我的个人网站项目。

## 目标

制作一个简洁、现代、适合手机和电脑浏览的个人网站。

## 页面内容

- 首页
- About Me / 关于我
- Skills / 技能
- Projects / 作品
- Contact / 联系方式

## 设计要求

- 简洁、现代
- 有设计感
- 手机端适配
- 页面不要过于复杂
- 可以有适量动画
- 中文为主
- 后续方便继续增加内容

## 开发要求

这是一个从零开始的新项目。

优先选择：
- Next.js
- TypeScript
- Tailwind CSS

代码结构要清晰，方便初学者理解。
